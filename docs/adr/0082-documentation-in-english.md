# ADR-0082: Documentation in English

- Status: Accepted
- Scope: `nuclear` (the repository it belongs to after the split, ADR-0083)
- Date: 2026-11-03

## Decision

All documentation is written in English: specs, guide, tutorials, context docs, ADRs, PRD and the website. Spanish becomes a later translation of the website. Code was already in English (ADR-0075). The chat with the user stays in Spanish. Exceptions of ADR-0075 remain (localization data, unicode tests).

## Alternatives rejected

Spanish documentation (ADR-0075).
