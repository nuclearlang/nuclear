# ADR-0038: Golden rule

- Status: Accepted
- Scope: `nuclear` (the repository it belongs to after the split, ADR-0083)
- Date: taken before 2026-11-03; migrated from `spec/decisions.md` on 2026-11-03

## Decision

Performance, speed and readability of the syntax, for the base language and every dialect. A rule, shortcut or kind is accepted only if it respects the three.
