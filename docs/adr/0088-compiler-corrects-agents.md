# ADR-0088: The compiler corrects agents: habits, invented APIs, words on demand, llms.txt

- Status: Accepted
- Scope: `nuclear` (diagnostics, CLI, type definitions, website)
- Date: 2026-11-03

## Context

The user asked (2026-11-03) that agents read and understand Nuclear, Dragonfly and every dialect "as if the model had
been trained on them". A model cannot be trained here (plan 001 §4); the measurement of ADR-0087 showed that the
brief alone changes little, because agents copy the project's `.nuc` and fail where they write by reflex. So the
knowledge goes where the agent already looks: the errors of the compiler and the shell.

## Decision

- **Habits (N0022, `crates/nuclear-syntax/src/habits.rs`):** a line scan, before the parser's errors, of the forms
  of TypeScript, Dart, Python, Java and Go: `{ }` blocks, `await`, `const/let/var/final x =`, `new`, `class A extends
  B`, `class A(B):`, the return type first (`int f(int x)`, `Widget build(BuildContext context)`), `def`/`function`/`fn`,
  trailing `:`, `elif`, `except E as e`, `None/True/False/undefined/nil`, `self`, `pass`, `lambda x:`, `#`
  comments, f-strings, backticks, `x++`, `import`/`from ... import`, `switch`, C `for (`. Each one gives the Nuclear
  form and, when exact, a `fix` (the hook and the LSP apply it). The other errors of those lines are dropped.
- **Invented APIs (F6 of plan 001):** in a file of a project (a single file cannot see its neighbours) with type
  definitions, a PascalCase call nothing defines is `N0220` (did you
  mean: edit distance over the project, auto-imports and globals) and a named argument the constructor lacks is
  `N0219` (it lists the real ones). `index.json` now carries `params` (the unnamed constructor) per class, so the
  build stays as fast (no `api.json` read); `tools/defs/index_params.py` adds them to existing packages and the
  Dart generator writes them. A class imported under that name from another package is not checked
  (`Dialect::def_libraries`). The names of `implicit` libraries are `globals`.
- **Words on demand:** `nuclear help <word> --dialect <d>` prints the `docs.toml` entry of a kind, decorator or
  header word (the same text as the editor's hover); `nuclear help words --dialect <d>` lists them with their first line.
- **llms.txt:** the website publishes `/llms.txt` (llmstxt.org: the sheets first, then the reference) and
  `/llms-full.txt` (every brief + the reference), generated by `website/scripts/sync.mjs` from the same files.
- The skill, the `AGENTS.md` template and the base brief say that the compiler corrects habits and how to look up
  words.

## Consequences

- An agent that writes TypeScript/Dart/Python by reflex gets one exact correction per line instead of a cascade of
  N0013; an invented widget or argument fails in Nuclear, not later in the target's compiler.
- 80 `.nuc` files of the repository and 242 documentation blocks give no N0022 (no false positives found).
- Not measured yet with agents: F7 of plan 001 (harder tasks) will tell how much it helps.
