# ADR-0056: ACL

- Status: Accepted
- Scope: `dragonfly` (the repository it belongs to after the split, ADR-0083)
- Date: taken before 2026-11-03; migrated from `spec/decisions.md` on 2026-11-03

## Decision

Based on Phalcon (roles that inherit others, permissions per role, everything denied unless allowed) and NestJS (guards: `guard` with `canActivate`). By default there is only logged in or not; roles are optional.
