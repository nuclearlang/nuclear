# ADR-0073: New dialects with agents

- Status: Accepted
- Scope: `nuclear` (the repository it belongs to after the split, ADR-0083)
- Date: taken before 2026-11-03; migrated from `spec/decisions.md` on 2026-11-03

## Decision

A new dialect is created by a coding agent (Claude, Codex, OpenCode) following the rules, process and restrictions of `spec/dialects.md` §8; each rule of its `spec.md` has at least one verified example. Per-project kinds and decorators are postponed.
